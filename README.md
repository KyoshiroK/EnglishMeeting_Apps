# Meeting Bridge — 英語会議の字幕・翻訳・回答アシスト

PCで使うGitHub Pages向けWebアプリです。左側に英語原文と日本語訳、右側に質問候補と日英の回答例を表示します。画面はビルド不要です。作成日：2026年10月30日。

**最初に `SETUP_JA.md` を開いてください。** 初回のみGitHub Pagesの公開、Cloudflare Workersの配備、OpenAI APIキー・利用トークンの設定が必要です。コピーだけで外部サービスの登録・認証まで済むものではありません。

| フォルダ・ファイル | 役割 |
| --- | --- |
| `docs/` | GitHub Pages公開用。HTML、CSS、JavaScript、音声Worklet、アプリのmanifest |
| `worker/src/index.js` | Cloudflare Workers用API中継。OpenAI APIキーをサーバーに保持 |
| `worker/wrangler.toml` | CLI配備設定。GitHubユーザー名だけ書き換える |
| `SETUP_JA.md` | Windows PCでの公開・利用手順、トラブル対応 |
| `DESIGN_JA.md` | アプリ構成、精度・速度の工夫、制約、今後の拡張 |
| `tests/` | 認証・音声区切り・ストリーミングなどの自動検証 |
| `VALIDATION_JA.md` | 実施済み検証と、公開後に必要な実機確認 |

画面には外部ライブラリー・広告・解析スクリプトを使用していません。会議テキストの表示には `textContent` を使用しています。

## 主な機能

- PCの再生音／ブラウザー会議タブの音声取得。代替にマイク入力。
- 英語の逐次文字起こし、日本語の暫定訳と確定訳。
- 文脈を使った質問・応答要求の自動判定。回答例2種類を日英表示。
- 背景・専門用語・本人が確認した事実の入力。
- 回答英文コピー、翻訳再実行、手動で回答例生成。
- 手入力での翻訳、テキスト履歴のダウンロード、デモ。
- アプリウィンドウとして開くためのmanifest。オフライン機能はありません。

## 必要なサービス

GitHub、Cloudflare Workers、OpenAI APIへのアクセス。インターネット接続と、ブラウザーの音声共有許可が必要です。OpenAI APIの課金・モデル権限を用意してください。サービス利用料は各社の最新条件に従います。ChatGPTへのログイン情報をこのアプリに入れる必要はありません。

## 動作対象

Windows PC＋最新版Chrome / Edgeを第一対象に設計しています。macOS / Linuxではブラウザー会議タブの音声共有を先に試してください。画面全体／アプリウィンドウの音声共有可否はOS・ブラウザーに依存します。ネイティブアプリの無許可録音機能はありません。

## 検証コマンド

Node.js 22以降で、リポジトリのルートから `npm test`。依存ライブラリー不要です。ブラウザーテストの実行方法は `VALIDATION_JA.md` を参照してください。
